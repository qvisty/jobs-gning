# Standard for casebilleder · grafisk facilitering

Ejerens faste prompt-skabelon for visuel kommunikation. Bruges som
kravspecifikation, hver gang der laves nye visualiseringer til siderne,
uanset om de tegnes som SVG eller genereres som billeder.

Stilkrav. Professionel håndtegnet stil, tydelige sorte streger, få
afdæmpede accentfarver, meget luft, aldrig barnligt. Kun den aftalte
tekst, korrekt stavet dansk, tydelig læseretning, tilstrækkelig
skriveplads i blanke udgaver. Undgå fotorealisme, logoer, mørk baggrund,
3D-effekter og overlappende elementer.

Kvalitetskontrol efter hver generering.
1. Alle krævede elementer er med.
2. Antallet af hovedområder er korrekt.
3. Al tekst er stavet præcist.
4. Ingen ekstra tekst er tilføjet.
5. Læseretningen er tydelig.
6. Der er tilstrækkelig skriveplads.
7. Den visuelle stil er ensartet.

Teknik i dette repo. Billederne tegnes som SVG (1200 x 675, liggende
16:9) med indlejret håndskriftsfont (Patrick Hand), sort tusch #1f2937,
gul markerfarve #fde68a og hvid baggrund. Genereringsscripts ligger i
sessionens scratchpad og kan genskabes ud fra denne beskrivelse.
